# Yekan Bakh font files

Place the licensed Yekan Bakh webfont files here after purchase.

Required filenames:

- `YekanBakh-Regular.woff2` — weight 400
- `YekanBakh-Medium.woff2` — weight 500
- `YekanBakh-SemiBold.woff2` — weight 600
- `YekanBakh-Bold.woff2` — weight 700/900 fallback

The project already references these files from `static/css/loomera-typography.css`.
Until the files are added, browsers will fall back to the configured Persian/system font stack.

Do not commit or redistribute font files unless your license explicitly allows it.
