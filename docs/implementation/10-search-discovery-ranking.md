# مرحله 10: جستجو، فیلتر، رتبه‌بندی و کشف سالن‌ها

## هدف

این مرحله جستجوی Loomera را از یک موتور ساده‌ی فیلتر سالن به یک لایه‌ی قابل توسعه برای کشف سالن‌ها تبدیل می‌کند، بدون بازنویسی UI فعلی جستجو و نقشه.

## تغییرات اصلی

- مدل‌های Analytics جستجو اضافه شد:
  - `SearchLog`
  - `SearchResultClick`
  - `SearchConversion`
  - `SearchAlias`
- سرویس‌های جستجو اضافه شد:
  - `SearchPaginationService`
  - `SalonFilterService`
  - `SalonRankingService`
  - `SearchLogService`
  - `AvailabilityWindowService`
- فیلترهای واقعی اضافه شد:
  - حداقل قیمت
  - حداکثر قیمت
  - حداقل امتیاز
  - فقط تخفیف‌دارها
  - وقت آزاد امروز
  - وقت آزاد این هفته
  - سالن تأییدشده
- sortهای جدید پشتیبانی شدند:
  - `rating`
  - `popular`
  - `discount`
  - `available_soon`
- availability با بافر خدمت و `occupied_until` هماهنگ شد.
- در availability، رزروهای آرایشگر در همه سالن‌ها لحاظ می‌شود تا تداخل چندسالن کاهش پیدا کند.
- خروجی نقشه کامل‌تر شد:
  - تصویر سالن
  - قیمت اصلی
  - برچسب تخفیف
  - تعداد نظرات
  - verified badge
  - rank
- endpoint ثبت کلیک نتیجه جستجو اضافه شد:
  - `POST /search/click/`
- صفحه فیلتر با patch حداقلی فعال شد و جایگاه‌های قبلی «فیلترهای آینده» به فیلتر واقعی تبدیل شد.

## اصول حفظ UI

- layout اصلی جستجو، نقشه و کارت‌ها بازنویسی نشد.
- global CSS تغییر نکرد.
- کلاس‌های Tailwind موجود حفظ شدند.
- فقط بخش فیلترهای بیشتر از حالت disabled به کنترل‌های واقعی تبدیل شد.

## دستورهای لازم بعد از اعمال

```bash
python manage.py migrate
python manage.py check
```

## تست دستی پیشنهادی

1. جستجو بدون فیلتر باید نتایج قبلی را نشان دهد.
2. sortهای پیشنهادی، نزدیک‌ترین، ارزان‌تر، بالاترین امتیاز، تخفیف‌دار و زودترین وقت باید بدون خطا کار کنند.
3. فیلتر تخفیف‌دار فقط سالن‌های دارای تخفیف خدمات را نشان دهد.
4. فیلتر حداقل امتیاز روی میانگین امتیاز سالن اثر بگذارد.
5. فیلتر قیمت بر اساس قیمت اصلی نمایش‌داده‌شده روی کارت عمل کند.
6. فیلتر وقت آزاد امروز/این هفته بدون نیاز به انتخاب تاریخ کار کند.
7. خروجی نقشه نباید خطای جاوااسکریپت بدهد.
8. `/search/results/` باید `count`, `page_count`, `total_pages`, `search_log_id` برگرداند.

## موارد باقی‌مانده برای مراحل بعد

- UI paging/infinite scroll در نتایج.
- fuzzy search کامل فارسی.
- اتصال SearchConversion به شروع/تکمیل رزرو.
- personal ranking بر اساس علاقه‌مندی و رزروهای قبلی.
- cache هوشمند search suggestions و نتایج پرتکرار.
