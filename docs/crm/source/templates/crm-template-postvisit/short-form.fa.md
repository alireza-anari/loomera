# Post-Visit Follow-up — Short-form Variants

## Push rule
Title کوتاه و state-led باشد. Body حداکثر ۷۰–۹۰ کاراکتر و فقط یک action داشته باشد.

## SMS rule
فقط برای action ضروری استفاده شود. یک link و یک CTA implicit کافی است.

## In-app rule
اگر email/SMS هم ارسال شده، in-app فقط shortcut و state را نشان دهد.
