# Feature Education — Email Template

- Template ID: crm-template-feature-education.email
- Brand: Loomera
- Direction: RTL / Persian-first
- Subject: یک راه ساده‌تر برای انتخاب زمان مناسب
- CTA: دیدن نحوه رزرو

## Body structure
1. State یا context را روشن کن.
2. جزئیات ضروری را کوتاه بگو.
3. یک reassurance معتبر اضافه کن.
4. فقط یک CTA اصلی بده.

## Tone
calm, trusted, refined, human, non-pushy

## Fallback logic
اگر tokenهای personalization ناقص هستند، جمله مرتبط حذف شود یا از عبارت عمومی انسانی استفاده شود. token خالی هرگز نمایش داده نشود.
