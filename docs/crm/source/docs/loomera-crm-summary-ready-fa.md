# Loomera CRM Template Set — Summary Ready

Loomera CRM باید یک سیستم ارتباطی آرام، دقیق و قابل‌اعتماد باشد؛ نه مجموعه‌ای از پیام‌های تبلیغاتی پراکنده. نقش اصلی CRM این است که کاربر را از discovery تا booking، reminder، payment، visit، review، rebook و support با کمترین ابهام همراهی کند.

## اصول اصلی
- اول clarity، بعد persuasion.
- در payment، booking و support همیشه `چه شد + اثر چیست + قدم بعدی چیست`.
- promotion محدود و tasteful؛ discount-first ممنوع.
- email برای توضیح و reference، SMS برای action ضروری، push برای nudge کوتاه، in-app برای guidance داخل flow.
- senderها تابع نقش باشند: رزرو Loomera، مالی Loomera، پشتیبانی Loomera، امنیت Loomera، ارائه‌دهندگان Loomera.

## CRM باید balanced باشد
استراتژی نهایی Loomera: **booking-led retention**. یعنی مسیر رزرو و تکرار رزرو مهم است، اما فقط وقتی پایدار می‌شود که trust، support، review و relationship building درست کار کنند.

## Families اصلی
Welcome، Discovery Nudge، Abandoned Booking، Booking Reminder، Pre-Visit، Post-Visit، Review Request، Rebook، Win-back، Favorites، Payment Recovery، Refund، Support Follow-up، Feature Education، Seasonal Campaign، Partner Onboarding.

## Tone نهایی
Calm confidence: روشن، انسانی، refined، بدون فشار، بدون کلیشه beauty و بدون urgency مصنوعی.
