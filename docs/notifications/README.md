# Loomera Notification Templates

این پوشه برای اتصال متن‌های in-app notification به CRM Template Set استفاده می‌شود.

## Canonical copy
فایل‌های notification در این مسیر قرار دارند:
`docs/crm/source/templates/*/inapp-notification.fa.md`

## Runtime skeleton
برای render ساده‌ی notification متنی:
`templates/notifications/loomera_inapp_notification.txt`

## اصول copy
- جمله‌ی اول وضعیت را روشن کند.
- جمله‌ی دوم اثر یا قدم بعدی را بگوید.
- CTA کوتاه و explicit باشد.
- برای خطا، پرداخت، لغو و تغییر زمان، قبل از ترغیب reassurance بدهید.
