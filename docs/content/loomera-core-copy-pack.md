## 1) Source Reading Summary

با توجه به Brand Voice Guide، Microcopy System، design tokens و typography handoff، Loomera باید برندی **آرام، refined، قابل‌اعتماد، دقیق و انسانی** باشد؛ برندی که تصمیم‌گیری برای خدمات beauty & wellness را روشن‌تر و رزرو را کم‌اصطکاک‌تر می‌کند. Voice باید **calm confidence** داشته باشد، نه هیجان‌زدگی تبلیغاتی؛ **premium but accessible** باشد، نه دور از دسترس؛ و در هر سطح، مخصوصاً booking، payment و support، قبل از ترغیب، اطمینان بدهد.

از نظر زبانی، مهم‌ترین محدودیت‌ها این‌ها هستند:  
- ابتدا شفاف‌سازی، بعد persuasion  
- هر جمله باید دست‌کم clarify، reassure یا guide کند  
- CTAها باید کوتاه، action-led و explicit باشند  
- در لحظه‌های حساس، ساختار متن باید «چه شد + اثرش چیست + قدم بعدی چیست» را رعایت کند  
- فارسی باید محترمانه، نیمه‌رسمی، طبیعی و بدون ترجمه‌زدگی باشد  
- clichéهای beauty، اغراق، over-feminine language و لحن noisy ممنوع است.

از نظر حسی، پالت Soft Violet، Lilac Mist، Sage Bloom و neutralهای روشن، در کنار تایپوگرافی sans-led برای محصول و serif-led برای brand، یک تجربه‌ی نرم، مرتب، روشن و quietly premium می‌سازند؛ بنابراین copy هم باید همین restraint و وضوح را ادامه دهد.

### نکته‌ی مهم از بررسی repo
در خود repo هنوز چند باقی‌مانده‌ی برند قبلی و namingهای legacy دیده می‌شود؛ از جمله حضور نام‌های قدیمی مثل **هویت قبلی پروژه** و token namingهای قدیمی مثل **legacy-design-namespace** در بعضی templateها و styleها. این Core Copy Pack همه‌ی touchpointهای محتوایی را روی برند **Loomera** یکدست می‌کند.

### تصحیح دامنه‌ی برند برای این نسخه
این نسخه بر مبنای scope دقیق‌تر برند تنظیم شد: Loomera فقط برای سالن‌های زیبایی نیست؛ بلکه رزرو خدمات beauty، درمان‌های زیبایی، ماساژ و مجموعه‌ی broader wellness را هم پوشش می‌دهد. بنابراین در copyهای پیشنهادی، framing از «salon-first» به «provider / center / specialist-first» گسترش داده شد.

### مهم‌ترین principleهای copy این پروژه
1. آرامش باید از وضوح بیاید، نه از شاعرانه‌نویسی.  
2. اعتماد باید از دقت بیاید، نه از ادعای بزرگ.  
3. premium بودن باید از restraint بیاید، نه از لحن پرزرق‌وبرق.  
4. هر متن باید قدم بعدی را آسان‌تر کند.  
5. Loomera باید «راهنما» باشد، نه «فروشنده‌ی پرسر‌وصدا».

## 15) Copy System Rules

### 10 rule اصلی برای Core Copy Loomera
1. **Clarity first.** هر متن باید سریع فهمیده شود.  
2. **Reassure before persuade.** مخصوصاً در booking، payment و support.  
3. **Premium through restraint.** نه اغراق، نه شعارزدگی.  
4. **Human, not chatty.** محترمانه و نزدیک، نه خودمانیِ زیاد.  
5. **Action-led CTAs.** فعل روشن + موضوع مشخص.  
6. **One decision per block.** هر بلاک روی یک تصمیم یا یک قدم متمرکز باشد.  
7. **No beauty clichés.** نه «بدرخش»، نه «معجزه»، نه «خاص‌ترین».  
8. **Specific beats generic.** «انتخاب زمان» بهتر از «شروع تجربه» است.  
9. **Status must be explicit.** در payment و booking، وضعیت باید بدون ابهام باشد.  
10. **Consistency across touchpoints.** همان برند باید در homepage، checkout، notification و support شنیده شود.

### Preferred phrasing patterns
- **Action + object**  
  رزرو نوبت / انتخاب زمان / مشاهده جزئیات  
- **State + reassurance**  
  پرداخت تأیید نشد. اگر مبلغی از حسابت کم شده یا نتیجه نامشخص است، دوباره پرداخت نکن و وضعیت همان تراکنش را پیگیری کن.  
- **What happened + next step**  
  نتیجه‌ای پیدا نشد. می‌توانید فیلترها را تغییر دهید.  
- **Choice-support pattern**  
  اگر این گزینه مناسب شما نیست، زمان‌های دیگر را ببینید.  
- **Trust-first pattern**  
  جزئیات رزرو پیش از نهایی‌سازی نمایش داده می‌شود.

### Wording to avoid
- شگفت‌انگیز  
- فوق‌العاده  
- جادویی  
- بی‌نظیر  
- لاکچری  
- بدرخش  
- زیبایی زنانه‌ات  
- بهترین انتخاب شما  
- شروع تجربه  
- بزن بریم

### How this core copy differs from microcopy
Microcopy برای line-level execution است: label، helper text، toast، modal، error، CTA و state message.  
Core Copy Pack برای **message architecture** است: یعنی بلوک‌های مرجع و متن‌های پایه‌ای که جهت کلی copy را برای homepage، marketplace، booking، support و partner surfaces مشخص می‌کند.  
به بیان ساده:  
- **Microcopy** = اجرای موضعی  
- **Core copy** = جهت‌گیری مرکزی و متن‌های مرجع

### How product team should use this pack
- هر surface جدید را ابتدا با بلاک‌های این pack map کنید.  
- headline، intro، reassurance line و CTA را از این pack انتخاب یا adapt کنید.  
- سپس microcopy line-level را با Microcopy System نهایی کنید.  
- اگر لازم شد copy کوتاه‌تر شود، tone را حفظ کنید ولی ambiguity اضافه نکنید.  
- در booking و payment، همیشه نسخه‌ی دقیق‌تر و status-led را ترجیح دهید.

### How marketing team should use this pack
- از taglines، positioning lines، hero copy و value propositionها به‌عنوان source of truth استفاده کنید.  
- copy مارکتینگ می‌تواند کمی expressiveتر باشد، اما نباید از calm confidence خارج شود.  
- promiseهای بزرگ یا claims مبهم را اضافه نکنید.  
- landingها باید desire را بعد از trust بسازند، نه قبل از آن.  
- companion lineهای انگلیسی فقط برای assetهای bilingual، SEO یا partner-facing materials استفاده شوند.

## Alignment fixes پیشنهادی برای repo فعلی

1. همه‌ی نام‌های **هویت قبلی پروژه** در titleها، headerها، support page و auth surfaces به **Loomera** تغییر کند.

   - «مشاهده و رزرو»
