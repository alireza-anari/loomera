# Loomera Docs Index

این پوشه مرجع human-facing و source-ready پروژه برای تیم‌های product، design، frontend، content، CRM، marketing، partner operations و support است.

## اصل تصمیم‌گیری
- **کد و runtime:** سورس پروژه در `loomera.zip`.
- **برند و محتوای canonical:** پکیج برند در `files.zip`.
- **تصاویر و binaryها:** داخل repo توسط این فاز کپی نشده‌اند؛ مسیر انتقال دستی در گزارش Phase 2، Phase 3 و Phase 4 آمده است.
- **متن، snippet، manifest و templateهای قابل version-control:** داخل همین `docs/` و چند template source-ready اضافه شده‌اند.

## Naming و legacy policy
در متن‌های human-facing از نام فعلی **Loomera** استفاده شود. اصطلاحات legacy فقط در این موارد مجازند:
- migration note
- compatibility alias
- مسیرهای قدیمی که برای runtime یا لینک‌های قبلی باید موقتاً حفظ شوند
- audit diffهای تاریخی

## وضعیت Launch Hero
در پکیج برند، asset مستقل با عنوان Launch Hero Banner پیدا نشد. فقط social launch template موجود است. بنابراین در این فاز asset جدید ساخته نشده و این مورد به‌عنوان missing باقی می‌ماند.
