# Handoff Spec — Loomera Partner Onboarding One-Pager

## Design Team
- سند RTL-native طراحی شود.
- لوگو فقط در header استفاده شود؛ از تکرار لوگو در کارت‌ها پرهیز شود.
- Violet رنگ هدایت‌کننده است، نه تزئین غالب.

## Sales / Partner Success / Content Team

## Frontend / Document Production Team

- برای PDF از A4 vertical استفاده شود.
