چه داده‌هایی ذخیره می‌شود؟

برای اتصال حساب Loomera به پیام‌رسان، شناسه پیام‌رسان، chat_id، نام نمایشی، نام کاربری، شماره موبایل در صورت ارسال توسط provider، وضعیت اتصال، رویدادهای webhook و لاگ ارسال/دریافت پیام ذخیره می‌شود.

توکن‌ها و دکمه‌های عملیاتی

توکن اتصال و توکن دکمه‌های عملیاتی زمان‌دار و یک‌بارمصرف هستند. مقدار خام توکن اتصال در دیتابیس نگهداری نمی‌شود و هنگام کلیک روی هر دکمه، کاربر، پیام‌رسان، وضعیت آبجکت و دسترسی همان لحظه دوباره بررسی می‌شود.

پیام‌های عملیاتی و تبلیغاتی

پیام‌های عملیاتی شامل نوبت، پرداخت، همکاری، مرخصی، پشتیبانی و پیام‌های سیستمی است. پیام‌های تبلیغاتی شامل پیشنهادها و کمپین‌هاست و جداگانه قابل خاموش‌کردن است. پیام‌های حیاتی امنیتی یا حقوقی ممکن است برای حفظ امنیت حساب و انجام تعهدات سرویس ارسال شوند.

قطع اتصال و حذف اثر ارسال

هر زمان می‌توانی اتصال ربات را از صفحه وضعیت اتصال قطع کنی. بعد از قطع اتصال، پیام جدیدی از آن اتصال ارسال نمی‌شود؛ اما لاگ‌های لازم برای امنیت، رفع خطا، حسابرسی و جلوگیری از اجرای دوباره اکشن‌ها طبق سیاست نگهداری داده Loomera باقی می‌ماند.

محدودیت providerها

هر پیام‌رسان ممکن است قوانین، API و محدودیت‌های خودش را داشته باشد. Loomera فقط قابلیت‌هایی را فعال می‌کند که provider به‌صورت امن و قابل اتکا پشتیبانی کند؛ انتشار خودکار استوری یا قابلیت‌های مشابه بدون API رسمی فعال نمی‌شود.
